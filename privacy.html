This Privacy Policy explains how RumboQuiz Studio ("the application") handles data. The application is an internal desktop tool used only by the owner of the RumboQuiz YouTube channel to upload the channel's own videos. It is not offered to the public and has no other users.

Use of YouTube API Services

The application uses YouTube API Services. By using it, the user agrees to be bound by the YouTube Terms of Service. Data handled through YouTube API Services is also subject to the Google Privacy Policy.

Data the application accesses

When the channel owner signs in with Google, the application requests permission to manage the owner's YouTube account (OAuth scopes youtube.upload and youtube). It uses this permission only to:

  • Upload videos created by the channel to the owner's own channel.
  • Set each video's title, description, tags, privacy status, scheduled publish time and thumbnail.
  • Add uploaded videos to the channel's own playlists and list those playlists.
  • Read the channel's name and the duration, privacy status and scheduled or published date of the channel's own videos, to propose the next publish date and to check that scheduled videos became public.

The application does not read or collect personal data, comments, subscribers, analytics or any information about other YouTube users or channels.

Data the application stores

  • The OAuth refresh token issued by Google to the channel owner, and the channel's ID and name.
  • The IDs, metadata and upload status of the videos it uploaded, so it can track its own upload queue.

This data is stored only on the channel owner's computer. It is never sent to any server other than Google's APIs.

Sharing of data

The application does not share, sell or transfer any data to third parties. Data is only exchanged with Google through the YouTube API Services, as required to perform the actions described above.

Cookies and tracking

The application does not use cookies, analytics or tracking technologies. This website does not set cookies either.

Revoking access and deleting data

Access granted to the application can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. Revoking access invalidates the stored token. All locally stored data can be deleted by disconnecting the account in the application or by removing the application's data folder. The stored token is deleted when the account is disconnected.
