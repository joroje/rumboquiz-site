RumboQuiz is a YouTube channel that publishes geography and travel trivia quizzes (flags, capitals, countries, monuments…), both long-form videos and Shorts. RumboQuiz Studio is the software we use to create those videos.

This is not a public service. RumboQuiz Studio is a desktop application that runs only on the channel owner's computer. It has no public sign-up, no other users and no web interface. This page exists to describe the tool and to host its privacy policy.

What the tool does

  • Generates geography quiz questions and lets the channel owner review them.
  • Renders the final video (MP4) locally.
  • Uploads the finished video to our own YouTube channel, youtube.com/@RumboQuizz, as a private video with its title, description, tags, thumbnail and playlist, scheduled to become public at a chosen date.

How it uses YouTube API Services

RumboQuiz Studio uses the YouTube Data API only to upload and organize videos on the channel owner's own channel, and to read the schedule and publication status of that channel's own videos. It does not access, read or store data from any other user or channel. See the Privacy Policy for details.
